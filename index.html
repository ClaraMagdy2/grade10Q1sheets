05 • Study Tips

How to revise for understanding

Before answering

  • Explain the term in your own words.
  • Look for the key idea, not a familiar answer position.
  • For code questions, trace values step by step.
  • Ask what the program should do before deciding what it actually does.

After submitting

  • Read every explanation, including questions you got right.
  • Write down the concept behind every mistake.
  • Try the new question set without looking at previous answers.
  • For debugging, identify syntax, runtime, or logic errors.
